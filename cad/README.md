# Mechanical design

- `inventor/original`: Inventor project, native assemblies, parts and available dependencies.
- `solidworks/simplified_assembly`: simplified assembly and rigid-body CAD groups.
- `step_exchange/full_assembly_and_parts`: neutral STEP exchange files.

Keep dependency paths intact. Automatic backup folders and CAD locks are excluded. MATLAB runtime geometry and XML export companions are kept separately under `simulation/Furuta_Project/geometry`.
